================================================================================
AUDIT LOGGING FEATURES
================================================================================

✅ CREATE Operations
   - Logs new client/loan/repayment creation
   - Captures: user, timestamp, object details, IP, user agent

✅ UPDATE Operations
   - Logs modifications with field-level change tracking
   - Captures: old vs new values in JSON format
   - Shows exactly what changed

✅ DELETE Operations
   - Logs single deletions
   - Preserves object information before deletion

✅ BULK DELETE Operations
   - Logs multiple deletions
   - Creates individual audit log for each deleted object

✅ Request Context
   - User who performed the action
   - IP address (with X-Forwarded-For support)
   - User agent (browser/client info)
   - Timestamp (automatic)

✅ Data Captured
   - Action type (CREATE/UPDATE/DELETE)
   - App label and model name
   - Object ID and string representation
   - Descriptive message
   - Field changes (for updates)

VERIFICATION COMMANDS
================================================================================

# Check audit log count:
docker compose exec web python manage.py shell -c "from audit.models import AuditLog; print(f'Audit logs: {AuditLog.objects.count()}')"

# View recent logs:
docker compose exec web python manage.py shell -c "
from audit.models import AuditLog
for log in AuditLog.objects.all()[:5]:
    print(f'{log.action} | {log.model_name} | {log.object_repr}')
"

# Count by action type:
docker compose exec web python manage.py shell -c "
from audit.models import AuditLog
print(f'CREATE: {AuditLog.objects.filter(action=\"CREATE\").count()}')
print(f'UPDATE: {AuditLog.objects.filter(action=\"UPDATE\").count()}')
print(f'DELETE: {AuditLog.objects.filter(action=\"DELETE\").count()}')
"
