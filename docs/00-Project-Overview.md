# Microfinance MIS (Ghana) — Project Overview
Owner: Onyameadamfo
Purpose: Build an on-premise Microfinance MIS with BoG-ready reporting, audit trails, and board-grade dashboards.

## Key Goals
- Loans + repayments + arrears + PAR/NPL + provisioning (MVP)
- Maker-checker approvals (loans, PVs, reversals)
- Audit trails for every action
- One-click reports (BoG-style outputs) and board dashboards
- White-label architecture for resale
